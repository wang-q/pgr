# 阶段 0 结论报告：.pgi 共享 syncmer 能否捕获 PAF 之外的共线性？（mg1655 × nissle1917）

> 2026-08-09。目标验证：pgr 能否用 `.pgi`（排序 syncmer 索引）实现"尽量捕获 PAF 之外
> 的高分歧/弱同源共线性区"（用户原思路，见 `design/pgi-ntsynt.md`）。结论：**信号不成立**。

## 1. 背景与假设

- 用户思路：`.pgi` 是 syncmer 的有序排列，应能像 ntSynt 那样，用**跨基因组共享 syncmer**
  信号定位 PAF 未覆盖但仍同源/共线的区域（高分歧、弱同源），从而"最大化共线性捕获"。
- 待验证（阶段 0 决策门）：**共享 syncmer 信号能否定位 PAF 未覆盖的共线性区？**

## 2. 实验设置

- 基因组：mg1655（ref，t 侧）× nissle1917（query，q 侧），`tests/genome/`。
- 数据：
  - `pgr pgi build`（k=40,16/20/24 多档 syncmer 8/5）→ 两 `.pgi`
  - `pgr align pgi` → 锚点 PSL（1299 块）→ PAF 覆盖
  - `pgr align lastz` → LAV → PSL（金标准覆盖）
- 工具：`examples/synteny_poc.rs`（读两 `.pgi` + PSL，算共享 syncmer 位置、PAF 覆盖、
  未覆盖区组成）。

## 3. 结果

### 3.1 共享 syncmer 信号几乎全在锚点覆盖内

| k | genome1 共享 syncmer 未覆盖位置 | genome2 未覆盖 |
|---|---:|---:|
| 40 | 92 (0.01%) | 84 (0.01%) |
| 24 | 698 (0.05%) | 330 (0.02%) |
| 20 | 1146 (0.08%) | 604 (0.04%) |
| 16 | 3166 (0.20%) | 3470 (0.21%) |

共享 syncmer（两基因组共有 k-mer）**99.8%+ 落在 PAF 已覆盖区**；k 降到 16 仍是 ~0.2%。

### 3.2 未覆盖区组成（genome1）

| 指标 | bp | 占基因组 |
|---|---:|---:|
| pgi 锚点覆盖 | 4,038,559 | 87.01% |
| lastz 覆盖（金标准） | 4,201,465 | 90.52% |
| pgi 未覆盖 | 603,093 | 12.99% |
| ├ **可捕获**（未覆盖 ∩ lastz，高分歧共线性） | 162,956 | 3.51%（占未覆盖 27%） |
| └ **株特异/无直系同源**（未覆盖 − lastz） | 440,137 | 9.48%（占未覆盖 73%） |

## 4. 解释

1. **为何共享 syncmer 信号无杠杆**：PAF 未覆盖的高分歧区里**没有共享 k-mer**（分歧太高，
   连低 k 精确匹配都留不下），或根本无直系同源。所以 `.pgi` 在那儿没有信号可定位——
   共享 syncmer 已被 `align pgi` 几乎全部捕获（99.99%）。
2. **未覆盖区大部分本就无可捕获**：73%（440 kb）是株特异/IS 元件/无直系同源，任何算法
   都捕获不到。
3. **真正可捕获的高分歧共线性区只有 3.51%（163 kb）**，且其中没有共享 syncmer——
   只能靠 **LASTZ**（`align fill`/`rest` 已在做）补，靠 syncmer 信号补不了。

## 5. 结论

- **原设计核心机制（用 .pgi 共享 syncmer 定位未覆盖区）已被数据证伪**，应放弃。
- "最大化共线性捕获"实际是 **LASTZ（fill/rest）** 的职责；fill/rest 已到 MAF 89.99%，
  lastz 上限 90.24%，**剩余差距仅 ~0.25 pp**，且属 LASTZ 打分/参数问题，与 syncmer 无关。
- 若目标是"跨 N≥3 基因组保守块"（ntSynt 语义），那是**另一类信号**（多路共享 syncmer
  求核心区），与 pairwise 未覆盖无关，需另行验证——但 pairwise 未覆盖信号极小，多基因组
  保守块大概率也只是 pairwise 覆盖的子集。

## 6. 后续选项（待用户定）

| 选项 | 内容 | 成本/前景 |
|---|---|---|
| A. 停，归档 | 接受负结果，不新建命令，计划归档 | 零成本 |
| B. 转向 fill/rest/LASTZ | 量化 fill/rest 能否吃满 lastz 上限剩余 ~0.25pp，必要时微调 LASTZ 参数 | 中；收益上限明确且小 |
| C. 多基因组保守块 | 多路共享 syncmer 求 N≥3 保守核心区（ntSynt 语义），先跑 3-4 株 cohort | 中；需先验证信号是否存在 |
